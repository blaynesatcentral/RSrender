# RSrender issue #18 prototype evidence

Throwaway primary-source artifacts for GitHub issue #18. This is not application code.

Serve this directory locally and open `index.html?variant=A`, `B`, or `C`. The three clean-room shells share one in-memory state/command model. `findings.md` records observed browser interactions, measurements, defects found, and the explicit evidence boundary.

The prototype supports a DOM/SVG-first next step; it does not establish production 60 Hz performance, WCAG conformance, or screen-reader usability.
