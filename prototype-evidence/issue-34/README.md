# RSrender issue #34 prototype evidence

Throwaway primary-source artifacts for the keyboard and accessibility evidence phase. Nothing here is application code or a conformance claim.

Serve this directory locally and open `accessibility-harness.html?variant=A`, `B`, or `C` to compare debounced, eager, and queryable status policies. `findings.md` records exact host/tool inventory, browser-observed keyboard and semantic behavior, failures found, simulations, unobserved assistive-technology/system-setting evidence, and release gates.

Narrator was installed but not launched because auditable speech/braille capture was unavailable; NVDA, JAWS, and Accessibility Insights were absent. Actual forced colours and 200% scaling remain unobserved.
