What each layer means

  • Application broker: one lifecycle/file command route. It does not make outside editors disappear.
  • Document owner: a stable session and generation for routing and deliberate handoff. A PID or marker is not authority.
  • Commit authority: a storage-specific exclusive critical section. A writer still rechecks the baseline inside it.
