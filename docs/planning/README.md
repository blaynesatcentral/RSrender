# Planning workspace

This directory is reserved for the Wayfinder-led planning pass.

The planning process should resolve at least:

1. Product boundary: renderer, visual designer, RSLog adapter, and optional preview service.
2. Data acquisition: public RSLog API, internal read endpoints, exports, or RSAgent canonical JSON.
3. Canonical boring-document schema, including laboratory results and presentation symbols.
4. Page, pagination, depth-scale, text-overflow, and shared-axis graph behavior.
5. Template storage, versioning, validation, and migration.
6. Golden-document and visual-regression testing.
7. Security, credentials, proprietary API boundaries, and open-source licensing.
8. Milestones separating proof of concept, usable renderer, and layout studio.

No architectural decision is recorded merely by appearing in this list.
