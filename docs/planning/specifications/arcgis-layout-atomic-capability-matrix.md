# ArcGIS Pro Layout atomic capability matrix for RSrender

Specification ticket: #15  
Synthesis date: 2026-08-13  
Status: normalized, evidence-backed benchmark matrix; product implementation is out of scope

## Purpose and authority

This matrix converts the six ArcGIS Pro Layout research reports into one implementation-facing capability inventory. It is not a request to reproduce ArcGIS Pro. Each row describes one user-observable outcome or one independently testable state transition, then classifies its use in RSrender as **Required**, **Adapted**, **Deferred**, or **Rejected**. Earlier evidence-frontier labels are reconciled below to the final domain, UX, lifecycle, product, architecture, recovery, and acceptance authorities.

The RSrender ubiquitous language in `CONTEXT.md` and settled Wayfinder decisions outrank benchmark behavior. ArcGIS evidence can decompose a problem and expose edge cases; it cannot silently define Log Template, Log Project, Log Document, Log Set, Reference Depth Range, Source Snapshot, Presentation Override, Diagnostic, Named Style, or Publication Audit behavior.

Source aliases used in every row are evidence links to the reports, which in turn cite first-party Esri documentation close to each atomic claim:

- **DM** — [document/page/Contents/hierarchy model](../research/arcgis-layout-document-model.md)
- **PI** — [selection/manipulation/precision interaction](../research/arcgis-layout-precision-interaction.md)
- **EP** — [elements/properties/styles/dynamic content](../research/arcgis-layout-elements-properties-dynamic-content.md)
- **TX** — [text measurement/overflow/pagination](../research/arcgis-layout-text-overflow-pagination.md)
- **LX** — [lifecycle/navigation/export/accessibility](../research/arcgis-layout-lifecycle-navigation-export-accessibility.md)
- **OB** — [observable-behavior evidence ledger](../research/arcgis-layout-observable-behavior-ledger.md)

Normalization rules:

1. One row represents one independently selectable command, state transition, persisted property, or failure outcome.
2. Repeated source rows are consolidated only when they describe the same outcome. Every contributing source ID remains in the source cell.
3. GIS-only structures remain visible when they reveal a reusable layout principle; their literal GIS behavior is classified Deferred or Rejected.
4. **Evidence-routed** never means “implementation agent decides.” Final product behavior is cited to a durable authority; remaining benchmark observation or release proof names a live gate and a fail-closed consequence.
5. “Feedback” means required user-observable response, not ArcGIS trade dress. Visual styling, icons, wording, and ornamental details require an independent RSrender design.

## Contradiction and deliberate-divergence register

| Topic | ArcGIS evidence | RSrender controlling decision | Matrix consequence |
|---|---|---|---|
| Page model | ArcGIS Layout is one physical page; map series iterate one shared composition and show one page at a time. [DM DM-03, DM-09–DM-10](../research/arcgis-layout-document-model.md), [TX PG-01–PG-03](../research/arcgis-layout-text-overflow-pagination.md) | A Log Set is a continuous generated page sequence with page-specific Reference Depth Ranges, Template Variant roles, diagnostics, and explicit overrides. | DOC-04 and PAG-01–PAG-05 are **Adapted/Rejected**; no implementation may import the map-series ownership model. |
| Alignment reference | ArcGIS aligns to the first selected element. [PI SEL-13, ARR-01–ARR-06](../research/arcgis-layout-precision-interaction.md) | The explicitly highlighted, last-selected **Key Element** remains fixed; users can promote another item. | SEL-07 and ARR-01–ARR-06 are **Adapted** and must expose the Key Element non-visually as well as visually. |
| Lock semantics | ArcGIS blocks canvas transformation but still permits Element-pane mutation. [DM VL-03](../research/arcgis-layout-document-model.md), [EP W06](../research/arcgis-layout-elements-properties-dynamic-content.md), [LX PROP-07](../research/arcgis-layout-lifecycle-navigation-export-accessibility.md) | **Effective Lock State** consistently gates transformation/property mutation while permitting inspection, visibility review, and explicit unlock; any exceptions must be enumerated. | TREE-12 and PROP-06 are **Adapted**; the pane-edit loophole is rejected. |
| Style propagation | ArcGIS copies a style on apply; later source/instance edits do not propagate. [EP P14–P16, S04](../research/arcgis-layout-elements-properties-dynamic-content.md) | **Named Styles** are live template definitions with explicit per-property overrides, reset-to-style, dependency inspection, and change preview. | STYLE-07–STYLE-10 are **Adapted/Rejected**; portability still requires stored resolved/migratable values. |
| Hidden guides | An official Esri tutorial states hidden guides still snap. [OB OB-PG-03](../research/arcgis-layout-observable-behavior-ledger.md) | A hidden RSrender guide is not an invisible snap target by default; visibility and snap participation are separate if later needed. | PREC-07 is **Adapted** and the ArcGIS coupling is rejected. |
| Nudge model | ArcGIS bare arrows pan; modifiers nudge by fixed points, with version-sensitive fine increments. [PI PRE-17–PRE-19](../research/arcgis-layout-precision-interaction.md), [LX NAV-02](../research/arcgis-layout-lifecycle-navigation-export-accessibility.md) | Canvas-focus arrows nudge a selected editable element using explicit document increments; viewport pan has separate routing. | XFM-11 and NAV-02 are **Adapted**; shortcut help must show effective distance and mode. |
| Reading order | ArcGIS tagged-PDF reading order follows drawing order, while current export UI also exposes an order list. [EP A04–A06](../research/arcgis-layout-elements-properties-dynamic-content.md), [LX EXP-25](../research/arcgis-layout-lifecycle-navigation-export-accessibility.md) | Semantic publication reading order is stored separately from render order and validated before export. | PUB-13 is **Adapted**; z-order changes cannot silently change assistive meaning. |
| Workspace dirty state | ArcGIS saves open/active views and some display state in its project boundary. [DM PS-01, PS-09–PS-10](../research/arcgis-layout-document-model.md), [LX NAV-15, LIFE-04](../research/arcgis-layout-lifecycle-navigation-export-accessibility.md) | Zoom, pan, pane geometry, active tab, selection, and transient filter state are workspace/session state and do not dirty a Log Template or Log Project. | DOC-12, NAV-06, and LIFE-04 are **Adapted**; ownership must be explicit per state. |
| Recovery | ArcGIS keeps one overwritten backup and may delete the original when recovery is accepted. [DM PS-03, PS-12](../research/arcgis-layout-document-model.md), [LX LIFE-15–LIFE-21](../research/arcgis-layout-lifecycle-navigation-export-accessibility.md) | Bounded integrity-checked Recovery Candidates written through the verified replacement lifecycle; preserve ambiguous candidates and require deliberate review. The [lifecycle conflict specification](lifecycle-conflict-state-command-specification.md#recovery-review-state-and-command-matrix) and [recovery policy](recovery-retention-privacy-policy.md) settle review commands, ordering, retention, privacy, and cleanup policy. | LIFE-10–LIFE-12 are **Adapted**; destructive Yes/No recovery is rejected. #36–#39 retain only mechanics and organizational-approval evidence. |
| Text continuation | ArcGIS supports flow among internal columns but no surveyed source establishes linked overflow frames or overflow-driven pages. [TX TT-07–TT-09, PG-08–PG-09](../research/arcgis-layout-text-overflow-pagination.md) | Semantically continuable content uses explicit stable source ranges, target order, continuation markers, and deterministic page/depth rules. | TEXT-14 and PAG-06–PAG-08 are **Adapted/Required** under [UX §12.3](layout-studio-ux-specification.md#123-overflow-contract) and [product §9.3](rsrender-product-specification.md#93-dynamic-text-and-overflow); internal paragraph columns are not Log Columns. |
| Export gating | ArcGIS may finish export with warnings and a warning file; no surveyed source documents a global overflow gate. [TX OF-14](../research/arcgis-layout-text-overflow-pagination.md), [LX EXP-08](../research/arcgis-layout-lifecycle-navigation-export-accessibility.md) | Diagnostic errors block; warnings require acknowledgement or narrow recorded suppression before immutable publication capture. | PUB-03–PUB-05 are **Adapted**; post-export warning-only behavior is rejected. |

## Finite remaining evidence frontier

The observable-behavior ledger remains clean-room benchmark evidence; it cannot reopen a settled RSrender command merely because an ArcGIS polish detail was not observed. ## Clean-room handoff rule

The normalized IDs are specification traceability identifiers, not names for implementation classes. Implementation agents may use the user goal, state, feedback, and failure contract but must not copy Esri code, assets, icons, strings, project formats, screenshots, branded interaction styling, or trade dress. Any licensed observation must follow the capture envelope and prohibited-action rules in the [observable-behavior ledger](../research/arcgis-layout-observable-behavior-ledger.md). Where an ArcGIS result conflicts with this matrix, the RSrender classification and contradiction register control until a deliberate product decision changes them.
